‹ 홈 MIDI 변환

MIDI 파일을 "곡 텍스트"로 바꿔서 내 음악에 등록해요.

1. MIDI 가져오기

방법 A. 인터넷 주소(URL)
대부분의 사이트는 다른 사이트에서 파일을 직접 받는 것을 막아서 실패할 수 있어요. 그때는 노트북 서버에서 이 페이지를 열면 노트북이 대신 받아 와요.
방법 B. 이 기기의 파일 선택 (PC에서 쓰기 좋아요)
방법 C. 노트북 MIDI 폴더 (노트북 서버에서 열었을 때만)

    곡 이름

    3. 곡 텍스트

    GitHub 앱 주소

    다른 기기(아이패드)에서 쓰려면: PC에서 "노트북 보관함에 저장" → 아이패드에서 노트북 서버의 이 페이지를 열고 아래 보관함에서 곡을 눌러 텍스트를 복사 → GitHub 앱의 내 음악에 붙여넣기.
